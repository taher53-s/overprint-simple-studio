# Start here

**OVERPRINT** is the selected project from the second round of 15 ideas. The first 15 were rejected. Read `docs/IDEA_PROCESS.md` for the complete process.

Team: Taher Sohagpurwala — 2409540; Harsh Agrawal — ID pending.

1. Install a Java Development Kit (JDK) version 17 or newer.
2. Open a terminal in this folder.
3. macOS/Linux: `chmod +x run.sh` then `./run.sh`. Windows: `run.cmd`.
4. Open **http://127.0.0.1:3000** in your browser.

The default study turns eight colours into four inks. The application includes an original/proof toggle, JSON palette import, configurable stock inks, error review, algorithm traces and downloadable outputs.

For your submission, start with `docs/Proposal.pdf` (2 pages) and `docs/Technical_Report.pdf` (7 pages). Editable Word copies are alongside them. `docs/VIVA.md` explains the demonstration and likely questions. `README.md` contains setup, API, limitations and test commands.

The code passes 22 named Java checks (including 1,200 oracle cases) and 19 HTTP integration checks. The managed browser could not initialise, so run the local browser checklist in `docs/VIVA.md` before presenting. `docs/preview.png` shows the exported artwork, not a browser screenshot.
