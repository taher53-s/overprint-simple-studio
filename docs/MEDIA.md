# Product film

42-second motion-graphics overview with moving colour groups, before/after wipe, animated slider and review cards.

The instrumental music is an original synthesized composition generated by scripts/make_promo.py: mellow chords, plucked melody, bass and light percussion. No third-party song or sound recording is used.

The file contains H.264 video at 1280×720 and stereo AAC audio at 48 kHz. English caption cues are in web/promo.vtt; a text explanation is available in the video dialog. Music begins only when the user chooses to play the film.

Regeneration requires Python dependencies in requirements-media.txt, FFmpeg, and DejaVu Sans fonts. Run python scripts/make_promo.py.

Validation: full video/audio decode passed, duration about 42 seconds, measured mean volume -20.5 dB and peak -5.6 dB before final 48-kHz encode. Frames from multiple scenes were visually inspected. Browser interaction and layout verification remains unavailable in this environment.
